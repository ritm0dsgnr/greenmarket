## Факты, влияющие на дизайн импорта

- Единого внешнего ID и единого артикула нет.
- Порядок и расположение колонок различаются между листами.
- В ряде строк указаны container, size и price без name. Таких строк 177.
- Есть нормализованно повторяющиеся названия, особенно в листах «Плодовые»,
  «Кустарники и деревья» и «Сопутствующие товары».
- Наличие может быть в отдельной колонке, в container либо свободным текстом.
  Встречаются не только «нет в наличии», но и временные примечания.
- Теги являются свободным текстом: встречаются маркетинговые отметки и
  служебные заголовки.
- Описание, латинское имя и характеристики заполнены не во всех листах.
- В листе «Лианы» поле availability содержит также значение, похожее на срок
  поставки, а не boolean availability.
- Есть строки с названием без числовой цены. Они не могут быть опубликованы
  без явного решения менеджера.

## Обязательные правила адаптера `greenmarket-price-v1`

1. Не применять generic importer по предположению о едином шаблоне.
   Использовать листовую schema map из этого профиля.
2. Сначала исключать служебные и заголовочные строки, затем валидировать
   candidate rows.
3. Пустая строка полностью игнорируется.
4. Строка с name без корректной цены попадает в preview как error или manual
   review, но не публикуется.
5. Строка с ценой и container, но без name не получает имя от предыдущей
   строки автоматически. Она требует ручного mapping в preview.
6. Строка с неизвестным availability, tag или container не интерпретируется
   как доступная по умолчанию.
7. Номер листа и строки сохраняются только в import journal и source mapping,
   а не используются как постоянный public ID товара.
8. Excel не создаёт, не меняет и не удаляет товарные фотографии.

## Поля, которые можно извлечь

Общий adapter должен нормализовать в промежуточную модель:

```ts
type GreenmarketPriceV1Row = {
  sheetName: string
  sourceRowNumber: number
  categoryLabel: string
  tagRaw?: string
  nameRaw?: string
  latinNameRaw?: string
  descriptionRaw?: string
  adultSizeRaw?: string
  containerRaw?: string
  plantSizeRaw?: string
  availabilityRaw?: string
  priceRublesRaw?: string | number
}
```

Эта модель является промежуточной и не должна напрямую сохраняться как
публичная сущность. После неё идут нормализация, валидация, mapping, preview
и только затем запись в единую модель каталога.

## Изменение файла в будущем

Этот xlsx признан стартовым source profile, но не постоянным шаблоном.
При подготовке следующей выгрузки рекомендуется:

- повторять name в каждой строке offer;
- не смешивать title, service text и data rows;
- оставить одну строку заголовков на лист;
- хранить availability в отдельной нормализованной колонке;
- выделить tag в отдельную колонку, а не в комментарии;
- не встраивать фото и не помещать URL к произвольным серверам;
- не менять смысл колонки без новой версии source profile.

Отдельный идентификатор в Excel не обязателен. Без него изменения строк
сопоставляются только по точному server-side fingerprint и ранее подтверждённой
карте. Всё неоднозначное требует действия менеджера.
